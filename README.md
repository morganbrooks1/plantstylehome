# Plant & Flower Care Guides

> Interactive HTML directory and visual search dashboard for **[PlantStyleHome.com](https://plantstylehome.com)** care guides, categorized by plant types, flower colors, birth months, seasons, and A–Z alphabetical collections.

---

## 📌 Features

- **Categorized Filtering:** Instant filter chips for All, Color Collections, Birth Month & Seasons, Houseplants & Trees, and A–Z Directory.
- **A–Z Index Navigator:** One-click quick jump filter for alphabetical botanical guides (A through Z).
- **Live Search:** Real-time search by plant name, common terms, or care topics.
- **Interactive Modals:** Built-in care detail popups for quick specs (sunlight requirements, watering schedules, difficulty ratings, and growing tips).
- **SEO & External Linking:** Optimized directory card layout featuring direct dofollow external link integration to key target authority pages on `plantstylehome.com`.
- **Fully Responsive & Clean Design:** Built with modern CSS custom properties (variables), responsive CSS grid/flexbox, and lightweight vanilla JavaScript (zero dependencies).
