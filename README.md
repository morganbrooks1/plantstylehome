# Plant & Flower Care Guides

> A modern, responsive, and interactive web directory showcasing plant and flower care guides for **[PlantStyleHome.com](https://plantstylehome.com)**.

---

## 📌 Overview

The **Plant & Flower Care Directory** is a lightweight, single-page application (SPA) designed to help users quickly search, filter, and access botanical care guides. Built with standard modern web technologies, it organizes articles into clean categories (Plants & Trees, Flowers by Color, Seasonal & Birth Flowers, A–Z Directory, and Unique Herbs & Crops) and provides instant care details via quick-view modals and direct links to full guides.

---

## ✨ Features

- **Instant Search Bar:** Live real-time search filtering across plant titles, tags, descriptions, and categories.
- **Categorized Tabs:** Easy navigation across 5 distinct plant & flower categories with dynamic count badges.
- **Quick-Care Preview Modal:** Interactive popups showcasing sun, water, and difficulty metrics before redirecting to full articles.
- **Direct Article Linking:** Clean outbound buttons linking directly to corresponding live articles on `PlantStyleHome.com`.
- **Fully Responsive Design:** Seamless layout adaptiveness across mobile, tablet, and desktop viewports.
- **Zero-Dependency Architecture:** Standalone single-file deployment utilizing CDN-hosted styling and icon frameworks.

## 🌿 Categories & Topics Covered

1. **🌳 Plants & Trees:** Monstera, Bamboo, Cat Palm, Umbrella Tree, Zygocactus, Dragon Fruit, Mesquite Trees, Autumn Blaze Maple, and Navigator Pear.
2. **🎨 Flowers by Color:** Red, Blue, Yellow, Pink, White, Green, Purple, Orange, Brown, Black, and Gothic Flowers.
3. **🌸 Seasonal & Birth Flowers:** Spring, Summer, Fall, Winter, Master Birth Flowers, Monthly Guides (July through December), Ranunculus, Asiatic Lily, Magnolia, and Night Blooming Jasmine.
4. **🔤 A–Z Floral Directory:** Alphabetical guides covering species from A through I (Azalea, Begonia, Camellia, Dahlia, Echinacea, Freesia, Gardenia, Hydrangea, Iris, and more).
5. **🌿 Unique Herbs & Crops:** Pravi Celer (Real Celery), Foenegriek (Fenugreek), Yalla Choy, and Lyposingrass.

---

## 🛠️ Technology Stack

* **HTML5:** Semantic structural markup.
* **Tailwind CSS (v3 via CDN):** Utility-first responsive styling and modern botanical color palettes.
* **Font Awesome (v6 via CDN):** Scalable UI and botanical iconography.
* **JavaScript (Vanilla ES6+):** In-memory array filtering, dynamic DOM rendering, modal handlers, and live search logic.

## 🚀 Quick Setup & Usage

1. **Clone or Download:**
   Clone the repository or download `index.html` to your local environment.

2. **Open in Browser:**
   Simply double-click `index.html` or open it using any modern web browser (Chrome, Firefox, Safari, Edge).

3. **Deploy to Hosting:**
   Since this is a self-contained single-file page, you can host it directly on:
   - **GitHub Pages**
   - **Netlify / Vercel**
   - **Standard Web Host (cPanel / Apache / Nginx)**
